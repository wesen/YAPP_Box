# DSL to YAPP OpenSCAD Mapping

## Goal

Define a practical mapping from the Enclosure DSL (YAML) to YAPPgenerator OpenSCAD parameters and functions to enable code generation.

## Context

YAPPgenerator is a parametric OpenSCAD toolkit to generate printable enclosures. Our DSL resolves to a fully numeric configuration. This document explains how each DSL section translates into YAPP variables and function calls, and outlines a minimal code generation strategy.

## Quick Reference

Top-level mapping:

- pcb.length/width/thickness → YAPP PCB dimensions
- pcb.z_clearance → vertical spacing below PCB; affects standoff height and base thickness
- pcb.holes[] → through-holes with yappHole on the relevant face
- pcb.standoffs → yappStand (named args: type, diameter, height, screw_d)
- enclosure.wall.thickness → wall thickness parameter
- enclosure.wall.clearance → inner clearance (boxInside)
- enclosure.wall.fillet_radius → corner rounding
- enclosure.base.thickness → base plate thickness
- enclosure.lid.type → screws|snap; screws.sizes map to countersink/counterbore
- features.holes → circular cut features (yappHole)
- features.cutouts → rectangular cutouts with fillet (yappCutoutRect/yappRing shapes)
- features.light_tubes → light tube constructs (per YAPP light tube examples)
- coordinates.{origin,reference_plane} → transform wrapper (translate/rotate)
- tolerances.{perimeter,holes,mating} → addend offsets applied during emit

Minimal codegen structure (OpenSCAD skeleton):

```scad
// Auto-generated by encl-resolve + dsl-to-scad
// Inputs resolved YAML as a JSON or SCAD define block

wall_thickness = W;                 // enclosure.wall.thickness
clearance = C;                      // enclosure.wall.clearance
fillet_r = FR;                      // enclosure.wall.fillet_radius
base_th = BTH;                      // enclosure.base.thickness

pcb_len = PL; pcb_wid = PW; pcb_th = PT; pcb_z_clear = PZ;

module place_origin() {
  // coordinates.origin / reference_plane mapping
  // pcb: translate([0,0,0]) ...
  // boxinside: translate([clearance, clearance, 0]) ...
  children();
}

module yapp_box() {
  // Use YAPP box generator with wall_thickness, fillet_r and clearance
}

module yapp_standoffs() {
  // For each pcb.standoffs: yappStand(type=..., d=..., h=..., screw_d=...)
}

module yapp_features() {
  // Holes
  // Cutouts
  // Light tubes
}

place_origin() {
  yapp_box();
  yapp_standoffs();
  yapp_features();
}
```

## Usage Examples

Example 1 — Base thickness from max:

DSL:
```yaml
enclosure:
  wall: { thickness: 2, clearance: 0.5, fillet_radius: 2 }
  base: { thickness: max(2.0, enclosure.wall.thickness) }
```

Generated SCAD (excerpt):
```scad
wall_thickness = 2;
clearance = 0.5;
fillet_r = 2;
base_th = max(2.0, wall_thickness);
```

Example 2 — Standoffs and holes:

DSL:
```yaml
pcb:
  z_clearance: 2
  standoffs: { type: round, diameter: 5, height: pcb.z_clearance + 4, screw_d: 2.2 }
features:
  holes: [ { face: top, x: 10, y: 10, d: 6 } ]
```

SCAD:
```scad
module yapp_standoffs() {
  yappStand(type=\"round\", d=5, h=6, screw_d=2.2);
}

module yapp_features() {
  // top face hole at (10,10)
  yappHole(face=\"top\", x=10, y=10, d=6);
}
```

Example 3 — Cutout with fillet:
```yaml
features:
  cutouts:
    - face: side_x+
      x: 40
      z: 12
      width: 10
      height: 6
      fillet: 1
```
SCAD:
```scad
yappCutoutRect(face=\"side_x+\", x=40, z=12, w=10, h=6, r=1);
```
